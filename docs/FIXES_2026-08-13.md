# Correcciones aplicadas — 13/08/2026

## Bugs encontrados y corregidos

### 1. `config_iva` multi-codificado (CORREDURIA y otras)
**Síntoma:** En Config IVA las reglas salían vacías aunque en la base de datos sí existían.

**Causa:** Al guardar, el servidor hacía siempre `JSON.stringify(config_iva)`. Si el frontend enviaba ya un string (porque había quedado doble-codificado de un guardado anterior), se volvía a codificar. CORREDURIA llegó a tener el JSON **triple-codificado**.

**Arreglo:**
- Se desanidaron todos los `config_iva` de la base hasta quedar un JSON de objeto limpio.
- `safeParseConfigIVA()` en el frontend tolera string, objeto o multi-codificado.
- El servidor ya no vuelve a hacer `stringify` si el valor ya es un string JSON válido.

### 2. Balanza de CORREDURIA julio sin números de cuenta
**Síntoma:** Papeles de trabajo de IVA, ISR, Estados Financieros y Analíticas no se llenaban para julio de CORREDURIA.

**Causa:** En `validarAmarre()` se guardaba la balanza así:
```js
cuenta: f.numero   // ← la propiedad real es f.cuenta
```
Quedaban todas las filas con `cuenta = undefined`. Solo se conservaba el nombre.

**Arreglo:**
- Corregido el guardado para usar `f.cuenta || f.numero` y deduplicar.
- Se reconstruyeron los códigos de cuenta de la balanza de julio de CORREDURIA cruzando nombres contra el catálogo (1402/1404 recuperadas).
- Todas las cuentas del amarre (103-0000, 204-0000, 503-xxxx, 106-0000) ya tienen montos reales.

### 3. Nombres con espacio al final
Se eliminaron espacios finales en nombres de empresa (CORREDURIA, MEDINEX, etc.) que podían impedir búsquedas.

### 4. Chip "Configurada" engañoso
Ahora solo muestra ✓ Configurada si hay al menos 1 regla real (no un `{}` vacío).

### 5. `calcularValorCuenta` sin normalización
Comparaba códigos con `===` estricto. Ahora usa `normCuenta()` (ignora guiones), igual que el resto del sistema.

## Qué debes hacer

1. Sustituye en tu instalación:
   - `orangematch.db` (base reparada)
   - `public/index.html` (frontend parcheado)
   - `server.js` (protección contra multi-codificado)
   - `data/empresa_17/balanzas/2026-07.enc` (balanza reconstruida)
   - `.data_key` (debe ser el mismo para poder leer los `.enc`)

2. Reinicia el servidor y recarga el navegador con Ctrl+F5 (sin caché).

3. Abre CORREDURIA → Config IVA: deben aparecer las 17 reglas.
4. Papeles de Trabajo → julio 2026: IVA debe llenarse desde el Anexo ya guardado; EF y Analíticas desde la balanza recuperada.

## Nota sobre ISR
`config_pt` de CORREDURIA sigue vacío (nunca se configuró el mapeo de cuentas de ISR para esa empresa). El papel de IVA y los Estados Financieros / Analíticas no dependen de eso. Para ISR por cuentas de balanza hay que configurar las reglas en "Configuración de Papeles de Trabajo".
